# ADR-046 — ADR 編號治理與衝突裁決記錄

**Status: ACCEPTED**
**Spec references:** §18, §39, §40.1
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

規格三處 ADR 表存在編號衝突：§39 表的 ADR-027..030 與 §18 的 ADR-027..030 內容不同；repo 亦曾以 ADR-031 記載 S1 graph 決策。裁決如下。

## Verifiable invariants

- §18 的 ADR-021..030 保留原編號（ADR 決策總表）
- §40.1 的 ADR-033..040 保留原編號
- §39 表的 ADR-031/032 保留原編號（Schema-as-Code / FMA Coverage）
- §39 表的 ADR-027..030 重編為 ADR-041..044
- repo 的 S1 graph 決策由 ADR-031 重編為 ADR-031a（內容不變）
- 新增 ADR-045（crate 命名）與 ADR-046（本治理決策）

## Consequence

每份 ADR 一檔、編號唯一；docs/adr/README.md 為索引。後續若規格改版再現衝突，依本 ADR 程序處理並新增 Superseding ADR。
