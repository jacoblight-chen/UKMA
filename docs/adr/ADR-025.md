# ADR-025 — 雙 Repository + 每 Slice 同步重構 + Contract Tests

**Status: ACCEPTED**
**Spec references:** §4.1, §4.2, §4.3, §4.4
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

codegraph-upstream.git 為不可修改 mirror，另設 reference checkout；UKMA 為全新 repo；唯一批准策略為 Mirror → Locked Golden Baseline → UKMA Contract → Migrate+Refactor Vertical Slice → Tests → Merge。

## Verifiable invariants

- 每 slice MUST 具 slice_id/source_sha/source_paths/target_crates/behavior_contracts/approved_differences/license_audit/golden_tests/contract_tests/rollback_plan
- license.identified=false 或 notices_preserved=false 時 MUST 阻擋 merge
- 禁止無證據重寫演算法

## Consequence

S0/S1 已依此執行；S2..S7 尚未開始。
