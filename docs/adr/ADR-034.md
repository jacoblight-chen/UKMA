# ADR-034 — 唯一公開 API Registry

**Status: ACCEPTED**
**Spec references:** §31.1, §32–§35, §36.1, §41.1
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

65 個 Domain OperationId 僅在 §32–§35 宣告一次；簡稱（如 store/update/promote）不得對外註冊。

## Verifiable invariants

- 13 + 14 + 25 + 13 = 65，ID 唯一（DOC-01）
- MCP tool 名稱由同一 Registry 產生
- 不得公開未經授權的 memory.promote alias

## Consequence

Registry 為 SDK/MCP/測試宣告的單一來源。
