# ADR-038 — 最小後端能力 Gate

**Status: ACCEPTED**
**Spec references:** §6.3, §28.2, §40.5
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

Capability negotiation 發生於啟動與 operation dispatch；不支援必要能力時拒絕，而非靜默降級。

## Verifiable invariants

- 最低 production profile 需 durable canonical transaction（含 outbox）、write idempotency、optimistic revision/CAS、typed key equality、revisioned read、delete tombstone、可靠 event replay、project-scoped ACL
- 缺任一必要能力 → CAPABILITY_UNAVAILABLE 並啟動失敗
- strict_generation 超時回 INDEX_NOT_READY 或 INDEX_STALE

## Consequence

禁止以舊快照偽稱 current。
