# ADR-021 — Database-Agnostic & Pluggable Persistence 是必須，不是選配

**Status: ACCEPTED**
**Spec references:** §1.1(4), §6.1, §6.2, §17.1 DB-001, §31.4
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

所有持久化 MUST 經由 Storage Ports；Domain crate MUST NOT 依賴 RocksDB、PostgreSQL、Neo4j、Qdrant、SQLite 特有 SQL/Schema、key format 或 SDK。系統 MUST 能在完全不載入 RocksDB runtime 的配置下完成 E2E，才可宣稱 DB-portable。

## Verifiable invariants

- Domain crate 無 vendor SDK import（ARC-001 掃描）
- RocksDB 僅能存在於 feature-gated adapter
- DB-008：無 RocksDB 配置完成 E2E

## Consequence

Backend 僅為可替換依賴；可攜性由 Adapter 契約測試證明，不由聲明證明。
