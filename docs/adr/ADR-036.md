# ADR-036 — 歷史與目前適用性拆分

**Status: ACCEPTED**
**Spec references:** §40.3, §35.1, §29.4 TR-001
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

KnowledgeRef/Evidence/TraceLink 對外 MUST 表達三個互相獨立維度：historical_validity、current_applicability、index_freshness。

## Verifiable invariants

- 新版本使 current_applicability=requires_revalidation，不得使歷史 valid 變 invalid
- 禁止以單一 stale 同時表示版本改變與索引落後
- coverage 只計 current_applicability=applicable 且索引達最低 generation 的連結

## Consequence

TraceState=stale 在 API v1 僅為重驗流程狀態。
