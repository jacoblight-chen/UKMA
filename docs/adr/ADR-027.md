# ADR-027 — Memory Consolidation 採證據先於提升的九步 DAG

**Status: ACCEPTED**
**Spec references:** §10.7, §27.1, §29.4 CO-001
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

Promotion 不得先於 Extraction 與 Confidence Calibration；執行順序唯一：Cluster → ExtractFacts → Align → DetectContradictions → Calibrate → Promote → WarmCache → OptimizeGraph → Rescore。

## Verifiable invariants

- ExtractFacts 不寫 SM
- CrossLingualAlign 不自動合併不等價規範
- DetectContradictions 不丟棄雙方證據
- Promotion 僅收非衝突且通過 gate 的候選
- CO-001：九階段順序、冪等與 checkpoint

## Consequence

明確修正歷史資料依賴矛盾（Alignment 獨立為階段）。
