# ADR-026 — UKMA v1.2.3 為獨立規格，Memory Domain 定義內建

**Status: ACCEPTED**
**Spec references:** §0, §10, §19, §20.1, §30
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

本文件為唯一自足架構與執行契約；Memory Domain 規範值、行為、例外、驗收條件均在本文重新定義，不需讀取任何外部 FMA 文件。

## Verifiable invariants

- 不得以「參照 FMA §x」作為必要依賴
- §22.1 為唯一 Budget 規範；§34.2 為唯一公開 Memory API Registry

## Consequence

外部文件僅為歷史來源定位資訊，不具規範效力。
