# ADR-043 — Immutable Revision, Evidence and Stateful Trace Verification

**Status: ACCEPTED**
**Spec references:** §35.2, §40.3, §31.4
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

接受後的 evidence immutable；補證據需新 revision 並重審；TraceLink 狀態機為 proposed→validated→accepted，rejected/revoked 為 terminal 不可復活原版本。

## Verifiable invariants

- validated/accepted→stale 於來源改版；stale→validated 需重驗
- 來源不可得時 MUST 保留 stale，不得自動 accepted
- PROP-06：accepted link 必有可訪問且版本匹配的 evidence

## Consequence

原 §39 編號 ADR-029，衝突重編為 ADR-043。
