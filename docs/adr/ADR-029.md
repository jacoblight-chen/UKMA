# ADR-029 — Public API 版本化；Private CodeGraph API 可重構

**Status: ACCEPTED**
**Spec references:** §4.4, §31.2, §42
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

Backward incompatible public API MUST 版本化並提供 migration guide；private API 不保證相容；canonical operation URI 為 ukma.<domain>.<operation>.v1。

## Verifiable invariants

- API major 與專案 release version 分離
- Server MUST 拒絕未知 major、未知 enum、遺漏必填欄位
- extensions 不得覆蓋核心欄位

## Consequence

v1.2.3 發佈時採 Public API v1。
