# ADR-030 — 初版 Modular Monolith，分散部署按實測決策

**Status: ACCEPTED**
**Spec references:** §3.1, §16
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

可先以 modular monolith 部署，再按量測結果拆服務；crate 邊界與 Port 契約先行，部署形態後定。

## Verifiable invariants

- 延遲與規模目標須經基準測試決策
- 不得把歷史設計估計當通用 SLA

## Consequence

避免了未量測即微服務化。
