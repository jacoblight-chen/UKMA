# ADR-028 — Knowledge Authority 與 Memory Authority 互不代管刪除權

**Status: ACCEPTED**
**Spec references:** §2, §10.8, §23.2, §29.4 SR-001, §40.5
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

知識層與記憶層可共存於同一實體 DB，但不得互為權威寫入者；Memory TTL/FSRS/RL 不得刪除 Source Artifact、Code/Document Knowledge 或 accepted TraceLink。

## Verifiable invariants

- DB-005：Memory TTL/FSRS 不可刪 Code/Document Authority
- SR-001：Code/Doc Source 不能被 Memory TTL/RL 刪除
- PROP-05：eviction/folding 皆通過 preserve gate

## Consequence

受影響關聯標 stale，來源證據依其來源保留政策維護。
