# ADR-024 — Authoritative writes + durable outbox + generation publication

**Status: ACCEPTED**
**Spec references:** §6.4, §6.5, §31.5, §40.4
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

先寫 canonical data、revision manifest 與 durable outbox（同一權威事務或可靠 coordinator），Index Consumer 再製作派生資料；派生索引可重建。

## Verifiable invariants

- Event delivery 至少一次；consumer 以 (event_id, consumer_id) 去重
- 不得將多 DB 操作暗示為全域 ACID
- READY 必須指向實際已同步的 revision/generation

## Consequence

Commit 成功與 projection 完成為正交狀態（見 ADR-037）。
