# ADR-040 — Schema Closed / Implementation Compliant 分級

**Status: ACCEPTED**
**Spec references:** §31.1, §38.3, §42, §43
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

四個階級必須明確區分：Catalog-Defined、Schema-Closed、Implementation-Compliant、Production-Ready；未交付 operation 級 schema 或未執行測試，不得宣稱 fully closed 或通過驗收。

## Verifiable invariants

- R1–R8 全部滿足方可宣稱 production-ready
- 單靠表格與 TypeScript 示意型別不構成 Fully Contract-Closed
- 任何 R1–R8 不滿足須標 specification-defined / implementation-incomplete

## Consequence

本專案目前：Catalog-Defined 已達，其餘三級未達（見 docs/implementation-status.yaml）。
