# ADR-023 — Logical IDs / Provenance 與 DB Schema 解耦

**Status: ACCEPTED**
**Spec references:** §0, §5, §5.1, §17.1 DB-003, §29.4 SR-002
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

ID 永不直接等於資料庫 primary key；ResourceRef 跨 DB 穩定；revision_id 必須是真實來源版本且不可虛構；未確認版本標 UNRESOLVED_SOURCE_REVISION。

## Verifiable invariants

- DB-003：切換 backend 後 IDs/ACL/Provenance/Revision 不變
- PROP-02：stable logical identity 不隨後端 Schema 或查詢順序改變
- 雜湊演算法與正規化版本寫入 manifest

## Consequence

S1 canonical ID（graph.node.<ULID>）即此決策的實作（見 ADR-031a）。
