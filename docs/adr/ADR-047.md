# ADR-047 — System API Minimal Contract

**Status: ACCEPTED**（owner 核准，2026-10-25）
**Spec references:** §36.4（強制存在 4 個 system API + SYS-01..04）、§31.2、§31.3、§41.2
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

規格 §36.4 要求 Public Gateway 提供 4 個共用管理 API，但**未定義其請求解與回應形狀**。本 ADR 定義形狀如下（已核准，非暫行）：

| OperationId | input（必填） | `data`（`status=ok` 時） | required scope |
|---|---|---|---|
| `system.capabilities` | （無必填；可選 `scope`） | `{api_major, operations_count, limits, adapters[]}` | `system:read` |
| `system.get_operation` | `operation_id` | operation registry 記錄（schemas、scopes、idempotency、concurrency、consistency_modes、error_codes、events、tests） | `system:read` |
| `system.get_job` | `job_id` | `OperationOutcome`（§40.4 正交 execution/commit/projection） | `system:read` |
| `system.cancel_job` | `job_id`, `reason` | `OperationOutcome`（cancel 僅停止後續作業，不抹除已 commit） | `system:manage` |

Schema 檔：`contracts/schema/v1/system.{capabilities,get_operation,get_job,cancel_job}.{request,response}.schema.json`（8 檔）。

## Verifiable invariants

- 4 個 operation 均使用同一 `RequestEnvelope`/`ResponseEnvelope` 形狀（`api_version:"1"`、固定 `operation` 常數）。
- 回應 `status=ok` 必須有 `data`、`status=error` 必須有 `error`（`allOf`/`if-then`）。
- `OperationOutcome` 為 job 狀態的唯一權威投影；`JobView.status` 不得用來推導 `canonical_committed`（ADR-037）。
- `system.cancel_job` 不得用於提交後回滾。

## Consequence

1. **已核准**（2026-10-25）。`system.*` 4 筆的 `closure_status` 不再被形狀決策阻擋，僅受 P0-WP3（schema 約束閉合）與 P0-WP5（CI 驗證）約束。
2. 核准後補 `contracts/fixtures/v1/system.*/{valid,invalid}` 正反例與 SYS-01..04 測試（P8）。
3. 若未來需要 `system.get_job` 回傳 `JobView`（§31.3 原始型別）而非 `OperationOutcome`，須新增 Superseding ADR；`OperationOutcome` 為 §40.4 的權威投影，`JobView.status` 不得用於推導提交狀態（ADR-037）。
