# ADR-045 — Crate 命名與目錄對照（§3.1 為權威命名）

**Status: ACCEPTED**
**Spec references:** §3.1, §39.2
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

規格存在兩套命名：§3.1（ukma-types / intelligence-core / graph-engine / storage-ports / adapters/* / ukma-mcp / ukma-cli / apps/ukma-server）與 §39.2（ukma-domain-code / ukma-domain-document / ukma-domain-memory / ukma-domain-traceability / ukma-storage-ports / ukma-storage-adapters / ukma-mcp-gateway）。本 ADR 以 §3.1 為權威，§39.2 為替代命名並以下表對照。

## Verifiable invariants

- crates/ukma-types ↔ ukma-types
- crates/ukma-contracts ↔ ukma-contracts（wire 契約，兩套命名一致）
- crates/graph-engine ↔ graph-engine（原 ukma-graph-engine 改名）
- crates/code-intelligence ↔ ukma-domain-code
- crates/document-intelligence ↔ ukma-domain-document
- crates/memory-domain ↔ ukma-domain-memory
- crates/traceability-engine ↔ ukma-domain-traceability
- crates/storage-ports ↔ ukma-storage-ports
- crates/adapters/* ↔ ukma-storage-adapters
- crates/ukma-mcp ↔ ukma-mcp-gateway
- legacy crates/ukma-code-runtime 無規格對等物 → 保留並標 deprecated（見 O-07）

## Consequence

經 owner 核准（2026-10-25）採用全面改名；改名不改變任何 wire 語意或公共 API 版本。
