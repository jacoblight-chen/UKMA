# ADR-037 — Canonical Commit / Projection 分離

**Status: ACCEPTED**
**Spec references:** §40.4, §6.4, §31.5
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

OperationOutcome 以 execution / commit / projection 三個正交 phase 表達；Commit receipt 可以成功且 projection pending。

## Verifiable invariants

- projection 失敗不得回滾已提交 canonical 資料，可重播
- JobView.status 不得用來推導 canonical_committed
- STORAGE_COMMIT_UNKNOWN 需 operation_id 與可驗證 receipt 查詢

## Consequence

取消僅阻止後續作業，不抹除已提交版本。
