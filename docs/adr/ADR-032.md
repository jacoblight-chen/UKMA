# ADR-032 — FMA Full Coverage Preservation Inside UKMA

**Status: ACCEPTED**
**Spec references:** §20, §29.1, §29.5, §34.1
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

§20–§29 的內建行為與 §34 API 必須保持一致；不得藉 typed wire model 移除 FSRS、RL eviction、paging、cross-lingual、reconsolidation 或 procedure lifecycle。

## Verifiable invariants

- coverage_matrix=100% disposition
- §29.4 的 40 項測試全綠
- 「演算法可選」不等於「功能可不存在」

## Consequence

Release gate 以 §29.5 判定。
