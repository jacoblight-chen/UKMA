# ADR-035 — 封閉錯誤碼

**Status: ACCEPTED**
**Spec references:** §31.3, §15, §43 DOC-02
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

ErrorCode 於一處定義為封閉 union；所有表格、schema、Rust enum 引用值必須屬其封閉集合。

## Verifiable invariants

- 未知 enum 必須拒絕或映射正式 UNKNOWN，不可自行推測
- 錯誤回應含 request_id、trace_id、code、retryable、safe_message
- 不得在 exception text 外洩 backend credentials

## Consequence

新增錯誤碼需 ADR 與 schema 同步更新。
