# ADR-031 — Schema-as-Code and Contract Test Gate

**Status: ACCEPTED**
**Spec references:** §31.3.1, §41.1, §41.2, §43 SCHEMA-01
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

Schema、Rust Types、SDK bindings、MCP manifest MUST 由單一 canonical model 產生或通過雙向 drift 測試；不存在於 Registry 的 tool 必須拒絕註冊。

## Verifiable invariants

- 每 operation 具 machine-readable JSON Schema Draft 2020-12（$id、$defs、封閉 enum、additionalProperties:false、bounds）
- CI schema-validate 驗證示例 request/response 與正反例
- PROP-10：所有 DSL/schema/generated bindings/mcp tools 同源且無 operation drift

## Consequence

此編號原屬 repo 的 S1 graph 決策，已重編為 ADR-031a（見 ADR-046）。
