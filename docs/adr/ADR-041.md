# ADR-041 — Unified Envelope and Versioned API v1

**Status: ACCEPTED**
**Spec references:** §31.2, §31.3, §31.5
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

所有 Domain 與 MCP 共用 RequestEnvelope<T> / ResponseEnvelope<T> 及統一錯誤語意；內部 Rust Port 可直接傳 RequestContext，但外部自報 tenant_id 不得越過認證層。

## Verifiable invariants

- 回應 request_id 與 trace_id 保持不變
- partial 必須帶 partial_reasons、不完整 domain/channel、freshness 與可見性限制
- Cursor 由伺服器簽署並綁定 query/scope/revision/snapshot/expiry

## Consequence

原規格 §39 表將此決策編為 ADR-027，與 §18 的 ADR-027 衝突；依 ADR-046 重編為 ADR-041。
