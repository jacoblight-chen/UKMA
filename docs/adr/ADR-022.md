# ADR-022 — 六種 Storage Ports 與能力協商

**Status: ACCEPTED**
**Spec references:** §6.2, §6.3, §28.2, §36.2
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

Graph / Vector / FullText / Metadata / Artifact / Outbox 六個 Port 為必要抽象；Adapter 啟動時 MUST 宣告 17 項能力欄位並與需求逐項比對，不支援必要能力 MUST fail-fast。

## Verifiable invariants

- 能力值經正式探測而非僅信賴設定宣告
- 降級必須在 Operation Policy 中宣告，回應帶 partial/freshness
- DB-007：必要能力缺失 → 啟動失敗

## Consequence

每個 backend 不必實作所有 Port，但任一缺口不得被靜默忽略。
