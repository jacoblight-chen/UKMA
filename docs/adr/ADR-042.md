# ADR-042 — Formal 4-Domain Port Contracts

**Status: ACCEPTED**
**Spec references:** §37, §36.2
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

四域各有正式 Rust port trait（CodeIntelligencePort / DocumentIntelligencePort / FractalMemoryPort / TraceabilityPort），65 項 Domain operation 禁止無契約的公開功能。

## Verifiable invariants

- IDL type ↔ Rust Request type ↔ JSON Schema $id ↔ MCP operation 1:1 映射
- OpContext 由 Gateway 認證後注入、非使用者可偽造
- Domain trait 禁止 import 資料庫 SDK

## Consequence

原 §39 編號 ADR-028，衝突重編為 ADR-042。
