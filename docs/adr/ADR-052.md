# ADR-052 Memory Advanced 實作決策（P6）

**Status: ACCEPTED**（owner 架構審批，2026-10-25）

**Spec references:** §23.3、§25、§26.1–§26.3、§27.1–§27.3、§29.2、§29.4、§34.2
**Related:** ADR-049（P3 服務形狀）、ADR-050（P4 文件服務）、ADR-051（P5 記憶核心）
**Supersedes:** ADR-051 **D-09**（P6 的 8 個 operation 改為已實作，不再回 `CAPABILITY_UNAVAILABLE`）

## 1. Context

P6 交付 §34.2 的進階 8 個 operation：MAPI-10／11／12（fact 提案、驗證、衝突）與
MAPI-18..22（九階段 consolidation、job 檢視、procedure 生命週期）。

同時實作 §24–§27 的演算法模組：trust 數學、poisoning 防護、多語言 gate、背景
維護 job 與熵整理。**沒有新增或修改任何 wire 級 operation**，65-operation registry
與 §31.4 全域語意未變。

## 2. Decisions

| ID | 決策 | 理由與後果 |
|---|---|---|
| **D-01** | Trust 一律分四欄（`source_reliability`／`claim_confidence`／`extractor_confidence`／`verification_state`）＋獨立 `authz_decision`（`Allow`/`Deny`，不是分數）；`T_rank=clamp(0.7*BetaMean+0.3*KalmanMean,0,1)`；Kalman 未初始化時退回 Beta 並回報 `beta_only_cold_start` | §26.1／§26.2／AG-003；低分不得翻轉授權、Deny 不得壓低分數，測試固化 |
| **D-02** | 重複轉述**不計獨立觀測**：`BetaState::record` 以 `source_group` 去重，同一 group 的成功/失敗只算一次 | §26.1「重複轉述不構成獨立成功次數」；TR-001 的來源去重 |
| **D-03** | Fact 三態：`Unverified → Verified | Rejected`，不可重複審查（`LINK_STATE_CONFLICT`）；驗證需提供**fact 上既有**的 evidence id（否則 `NOT_FOUND`）；被矛盾且未解決的事實**不得**被 verify（`POLICY_DENIED`），但可 reject | §34.2 MAPI-11、§27.1「衝突保留雙向佐證」 |
| **D-04** | Promotion gate：`independent_source_groups >= 3` 且 `confidence >= 0.65`；`manual_approval_ref` 只可**豁免群組數**，不可豁免 safety／ACL／hold／缺 evidence／未解衝突，且必須有 reviewer、理由、已驗證來源、合法採集、未過期 | §27.1 可稽核例外；不符合時 gate 回報每個 reason 而非靜默通過 |
| **D-05** | 九階段順序唯一 `Cluster→ExtractFacts→Align→DetectContradictions→Calibrate→Promote→WarmCache→OptimizeGraph→Rescore`；**只有 Promote 會寫 canonical SM**；Promote 之後的 `WarmCache` 失敗 → `FAILED_RETRYABLE` 且**不回滾已提交事實**；重放同一 stage＋同一 `input_hash` 為冪等（不消耗 attempt）；`Quarantined`/`FAILED_FINAL` 後不得再跑 | §27.1；CO-001；`checkpoint:{job}/{stage}` 與 `audit_ref` 逐步記錄 |
| **D-06** | `memory.consolidate` 雖回 `JobHandle`，本 build **同步**跑完九階段後才回傳；`async:false` 直接 `INVALID_ARGUMENT`；pipeline 狀態即 job 的 `stage`，`canonical_committed` = Promote 是否已完成 | §34.2 要求 async 語意；不假裝背景執行佇列（真排程屬 adapter／P7+），但語意與可觀測欄位齊備 |
| **D-07** | Poisoning：`source_mutated`／`writes_last_hour>240`／`contradictions_last_hour>5`／`trust_delta_z<-2`／譯文夾帶指令 → `QUARANTINED`；來源被隔離時 `verify_fact` 回 `POLICY_DENIED`、consolidation 於 `DetectContradictions` 回 `QUARANTINED` 並凍結 promotion；只可由具 reviewer／理由／snapshot 的離線審核恢復 | §26.3、TR-002；注入文字仍分類為 **Data**（`PayloadClass::Data`），只觸發訊號 |
| **D-08** | 多語言只做**script 辨識**（`und-Hans`/`und-Latn` 等），段切保留原始 byte offsets；`lang_match` 1.0／0.85／0.425、`omega_align=min(1,align/0.85)`、`theta_align=0.85`、`theta_cross=0.75`；跨語合併需 entity match＋對齊相似度＋qualifier 相容＋provenance 有效 | §25.1／§25.4／ML-001／ML-004；腳本 ≠ 語言，不以偽語言分類器冒充 |
| **D-09** | Translation cache key 必含 `text_hash, source_lang, target_lang, translator_version, acl_scope, source_revision`（`acl_scope` 讓租戶間不可能共用），TTL 24h；語言偏好採 Laplace prior `alpha=1.0`，**明示設定優先於學習值** | §25.4 |
| **D-10** | Embedding profile 身份包含 model/revision/dimension/metric/tokenizer/normalization/quantization；任一不同 → `requires_new_generation`（需新 index generation＋原子 alias 切換）；Matryoshka 截斷只有在 ≥1024 維才是 `Full`，512／256 需本地品質測試（本 build 無法執行 → `RequiresLocalQualityTest`） | §25.2、ML-003；不宣稱未測的截斷可用性 |
| **D-11** | Procedure trial（候選期試跑）**可以**記錄 outcome，否則 `calls>=3` 的 consolidation gate 永遠不可達；`Disabled` 之後不得再記錄；成功率先以 Beta 後驗 `(1+s)/(2+calls)`，1 次成功＝0.667 不是 1.0；`ACTIVE` procedure **不授予任何工具權限** | §27.2、PM-001；狀態與權限分離 |
| **D-12** | `review_procedure(activate)` 對 Candidate 先做**純檢查**（`consolidation_ready`），不足即 `POLICY_DENIED` 且**不推進 revision**；達標才 consolidate→activate | 避免失敗呼叫造成 etag 漂移（實作時由測試抓到的真實缺陷） |
| **D-13** | 背景維護 job：9 種 kind、tenant 分割、idempotency key（同 tenant+kind+key 重用既有 job）、lease＋**fencing token**（過期才可被接管，舊 token 不得 complete/fail）、指數 backoff（5s×2^(n-1)）到 5 次進 dead letter、`checkpoint` 供重啟續跑、FSRS sweep 每 1h | §27.3、PROP-09、OPS-001 |

## 5. 已知缺口（不得宣稱完成）

1. **Consolidate 是同步執行**：狀態與欄位符合 §27.1，但沒有真正的背景 worker 佇列；`Scheduler` 已有 lease／fencing／DLQ 原語，尚未接到 `consolidate`（屬 adapter／部署階段）。
2. **Promote 只驗證既有 fact 候選**：沒有從 episode 直接抽取新事實的抽取器（需要模型），`ExtractFacts` 階段的輸出因此是既有候選集合的投影。
3. **多語言只到 script 層**：無 ICU／jieba／Kuromoji 分析器、無翻譯服務、無跨語向量對齊；translation cache 只提供 key／TTL／隔離語意，未實作實體快取。
4. **Semantic fact 未進入跨文件 `memory.search`**：目前僅透過 `find_conflicts` 取得（`p6_matrix::facts_are_not_silently_indexed_into_cross_document_search` 明確固化此限制）。
5. **無 trust 的 Kalman 量測來源**：量測值由呼叫端提供，尚未接上 review 事件流。
6. **Poisoning 偵測為規則式**：`instruction_like` 是樣式啟發法，不是分類器；`restore_source` 由政策面呼叫，未串接審核 UI。
7. **無 1M episode benchmark**（FM-010）：未宣稱任何延遲或容量 SLA。
8. **Procedure 無 skill 編譯**：`tool_scope` 只是需求宣告，Capability Registry 綁定屬後續階段。
9. **Entropy 整理未自動接線**：`entropy::decide/verify` 已實作且可測，但 `entropy_candidate_scan` job 尚未驅動實際改寫。
