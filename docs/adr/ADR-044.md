# ADR-044 — Job, Idempotency, Outbox and Generation Semantics

**Status: ACCEPTED**
**Spec references:** §40.4, §7.5, §31.4
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

非同步操作可恢復且可區辨最終提交狀態；跨 DB 明確 eventual 與 strict 邊界；所有產生 side effect 的 API 必須提交 idempotency_key。

## Verifiable invariants

- 同 key + 不同 payload/hash → IDEMPOTENCY_CONFLICT
- 修改既有資源需 expected_etag 或 expected_revision，衝突 ETAG_MISMATCH
- PROP-09：cancel/timeout/retry 不刪除已提交權威資料

## Consequence

原 §39 編號 ADR-030，衝突重編為 ADR-044。
