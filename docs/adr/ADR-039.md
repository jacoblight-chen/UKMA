# ADR-039 — 操作、事件、狀態、Schema、測試單一 Registry

**Status: ACCEPTED**
**Spec references:** §40.6, §41.1, §39.2
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

不允許表格、Rust、MCP 三份來源各自手寫造成 drift；所有事件型別須在正式 Registry 宣告後才可發佈。

## Verifiable invariants

- 每事件具 event_type/event_version/aggregate_kind/payload_schema_id/required_scopes/producer/consumers/ordering_key/dedup_key/privacy_class/retention_policy
- 每 operation 具 15 欄位（§41.1），缺一 → Release Gate FAIL
- PROP-10 漂移檢測

## Consequence

CI contract-closure-check 為執行機制（P0-WP5）。
