# ADR-033 — Context budget 唯一算法

**Status: ACCEPTED**
**Spec references:** §10.2, §22.1, §40.2, §29.4 CT-001/CT-002
**Source:** UKMA v1.2.3 (`docs/UKMA_v1.2.3_Full_Spec.md`)

## Decision

唯一公式：C_usable = W_model - R_system - R_output - R_runtime；B_eff(d) = min(C_usable, max(4096, floor(min(C_usable,131072)/4^d)))；C_usable < 4096 回 INSUFFICIENT_CONTEXT_BUDGET。

## Verifiable invariants

- 不得二次扣 reserve（R_system 已含 system/tool/security tokens）
- 分區配額 floor(B_eff*share)，餘數入 Message Ring，三者和恰等於 B_eff
- §40.2 六組決定性向量：65536/d0→65536、d1→16384、d2→4096；131072/d1→32768；32768/d3→4096；4095→error

## Consequence

任何章節不得另行計算 budget 或假設主代理 WM 固定 4K。
